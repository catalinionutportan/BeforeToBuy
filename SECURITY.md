# Security Policy

## Supported versions

Security fixes are applied to the current production deployment of BeforeToBuy.com (`main` branch).

## Reporting a vulnerability

Please report security issues privately to **admin@portanx.com**.

Include:

- A short description of the issue and impact
- Steps to reproduce or a proof of concept (non-destructive)
- Affected URL(s) or component(s), if known

Do **not** open a public GitHub issue for sensitive vulnerabilities.

We aim to acknowledge reports within a reasonable time and will coordinate disclosure after a fix is available.

## Scope

In scope: BeforeToBuy.com web application, public APIs, and related configuration in this repository.

Out of scope: third-party merchant checkouts, affiliate network platforms (AWIN, 2Performant), and vendor control planes (Cloudflare, Supabase, etc.), except where a misconfiguration in this project causes exposure.
